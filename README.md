# UPNEX-Beyond-the-Static-Resume-Your-Career-s-Operating-System
UPNEX reimagines how students document their journey. Combining GitHub-style proof-of-work, AI-driven career pathing, and a secure credential vault, UPNEX gives students a living digital identity that continuously tracks, verifies, and showcases their real-world skills.

Stop listing your skills—start proving them.

UPNEX is an AI-powered Student Intelligence and Digital Identity Platform designed to replace static resumes with dynamic, verifiable proof of academic and technical growth. By combining GitHub-style proof-of-work tracking, LinkedIn-style student networking, and AI-driven career pathing, UPNEX gives students a unified workspace to document, verify, and showcase their real-world skills.

Key Features
Verifiable Proof-of-Work: Track academic projects, skill milestones, and repository contributions with transparent, verifiable proof of progress.

Digital Student Twin: AI-driven analytics that model career trajectories, identify skill gaps, and provide actionable development insights.

Student Network & Portfolio: A modern digital presence built specifically for student portfolios, peer collaboration, and technical showcasing.

Secure Credential Vault: A centralized workspace to securely store, manage, and share verified academic records, certificates, and project artifacts.

Modern UI System: Designed with fully accessible Dark and Light modes tailored for daily productivity.

## Current Flow

`/` Landing page -> **Explore UPNEX** -> `/dashboard` Main learning workspace

The current frontend uses a direct no-login flow. The dashboard does not require PostgreSQL or Prisma.

## Run on Windows

Open PowerShell in this project folder and run:

```powershell
npm run dev
```

The root script installs frontend dependencies before starting Vite. Open the local URL Vite prints, normally `http://localhost:5173`.
