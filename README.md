# UPNEX — Insane Education Experience

UPNEX is a cinematic futuristic education ecosystem with a direct no-login flow.

## Flow

`/` Landing page → **Explore UPNEX** → `/dashboard` Main learning workspace

There is no login wall. The dashboard is a front-end experience and does not require PostgreSQL or Prisma.

## Run on Windows

Open PowerShell in this project folder and run:

```powershell
npm run dev
```

The root script automatically installs the frontend dependencies before starting Vite. Then open the local URL Vite prints, normally `http://localhost:5173`.
